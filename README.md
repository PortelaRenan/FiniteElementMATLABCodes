## 📌 About

This repository gathers MATLAB codes that implement the **Finite Element Method (FEM)**. They were developed as part of my graduate coursework in course **IM381** at **UNICAMP** (University of Campinas, Brazil), during my Master's in Mechanical Engineering.

Each script solves one assignment of the course. They are meant as **study material**: short scripts that show how the method works, from the discretization to the solution of the system of equations.

> 📚 File names and some comments are in Portuguese, since the course was taught in Portuguese. "Atividade" means "assignment".

## 🚀 How to run

**Requirements:** MATLAB.

```matlab
% 1. Clone or download this repository and open the folder in MATLAB
% 2. Run any script by typing its name in the Command Window:
IM381_atividade1
```

You can also open a script in the MATLAB editor and click **Run**.
